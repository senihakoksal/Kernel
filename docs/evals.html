Observation Kernel

Evals

Did the agents do what their prompts asked? These checks are about the instrument, not the result — they are run against every log and they have right answers.

Change a prompt, run again, and read down a column: a green that turns red is a change you caused. Nothing here uses a model to judge, so it costs nothing to re-run as often as you like.

Convergence is deliberately absent from the pass/fail criteria. Critics growing alike is the thing the project studies, so a red light on it would be a category error. Those appear further down as measurements, with no verdict.

Criteria

Only runs with a matched control arm. A run without one is a test run: its criteria still pass or fail, but the two measurements that matter — what survives isolation — have nothing to compare against, so it is left out rather than padding the table. One row per run, newest first. Each cell shows the measured value; the colour is a second signal, never the only one. Hover a cell for the rule it was judged against. Columns are ordered by what they tell you: what the agents did first, output format last. Each run is judged against the length rule it was actually given, recorded in its own sidecar — so editing the prompt will not retroactively turn old rows red.

What each check means

Thresholds

Where each criterion's pass and warn lines sit. Conventions, not laws — stated here so they can be argued with rather than discovered by reading the source. The measurements below have none by design: there is no threshold at which critics agreeing is correct or incorrect.

Measurements

No pass or fail. These are what the run found, and where a control exists the isolated arm is given beside it — what survives isolation is shared instinct rather than influence. Runs with only a handful of critiques are marked: these statistics need a sample, and the early June runs do not have one.

What each measurement means

None of these has a pass or fail. They are what the run found.

Judged checks

Two questions need a reader rather than a rule: does a critic actually write its disposition, and is the score legible from the prose attached to it. Everything above this point is free and deterministic. These are not — they are put to a reader, and that reader is itself under test.

How the judge is asked

The method, and the prompts verbatim. Both are read out of judge.py rather than restated here, so neither can drift from what the judge was actually sent.
