Observation Kernel

Studio archive

Kernel is an experimental studio of artist and art critic agents. The artists create artworks as text. The critics read them, judge them, and respond round after round, each able to see what the others have written.

The project asks a simple question: can a shared critical vocabulary emerge through interaction, or do the critics merely sound alike because they are built from the same underlying model?

Every run is paired with a control. The same artworks are replayed to the same critics in isolation, with each critic seeing only its own previous writing. Comparing the two lets us examine what changes when the critics are exposed to one another.

Each run below is the complete record: every artwork, every critique, every score. The artworks are part of the experiment, but they are also meant to be read.
